I help teams start using AI in their daily work. I studied how people work with AI tools in intercultural consulting teams (MA International Management, Hochschule Fresenius, thesis graded 1.3), published the results in 2026, and built two AI learning apps with the Claude API that people use today.

Before that I worked at Accenture in Berlin on an SAP IDM programme, and at Accenture in Bangalore in IT operations for clients like E.ON, GSK and Whirlpool.
